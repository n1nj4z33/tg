# ☢ РАДКЛУБ

Telegram Mini App: пошаговый «бойцовский клуб» в постапокалипсисе. Бой — через прицельную систему **П.Р.И.Ц.Е.Л.**: тратишь очки действия на очередь выстрелов по частям тела (голова, глаза, торс, пах, руки, ноги), видишь шанс попадания по каждой и смотришь, как у врага разлетается голова, отрываются конечности, тело превращается в пепел (лазер) или в лужу слизи (плазма).

Мир — реальные секретные места: Академгородок и НИИ «Вектор» (Новосибирск), Кольская сверхглубокая СГ-3, Тунгусский эпицентр, бункер Ямантау, РЛС «Дуга» (Чернобыль-2), Метро-2 под Раменками, Зона 51 / S-4.

## Что есть

- **Бой П.Р.И.Ц.Е.Л.**: 8 частей тела, у каждой свой штраф к меткости, множитель урона и шанс крита. Покалеченные части дают эффекты: ослеп (−25% меткости), контузия (−2 ОД), повреждённые руки/ноги, удар в пах — пропуск хода. Патроны тратятся по-настоящему, стимуляторы можно колоть прямо в бою.
- **6 видов смерти** с анимацией: взрыв головы (мозги, кости, глазное яблоко), отрыв конечности, разрыв торса, пепел, слизь, обычное падение.
- **Прокачка**: 7 характеристик (СИЛ/ВОС/ВЫН/ХАР/ИНТ/ЛОВ/УДЧ), 6 навыков, 12 перков, уровни.
- **Инвентарь с весом**: перегруз запрещает путешествия и вылазки. Оружие, броня, шлемы, медицина, патроны, хлам и трофеи.
- **7 поселений** со своими торговцами, ночлегом, проблемами и цепочками квестов (17 заданий). **8 опасных зон** с радиацией, тайниками, ловушками и боссами.
- **Арена (ринг)** в каждом поселении: бои со снимками других игроков и местными бойцами, рейтинг Эло, таблица лидеров.
- Регенерация ОЗ по реальному времени, засады в пути, радиация снижает максимум здоровья.

Графика полностью векторная и рисуется кодом (SVG-компоненты): существа собраны из отдельных частей тела, поэтому их можно подсвечивать в прицеле, ранить, отрывать и взрывать.

## Структура

```
packages/engine   общая игровая логика (чистый TypeScript, без зависимостей):
                  контент, формулы, бой, квесты, арена, редьюсер applyAction()
apps/web          React 19 + Vite: экраны, UI-кит, SVG-арт
apps/server       Node + Fastify: авторизация Telegram, хранение, арена между игроками
```

Движок один и тот же у клиента и сервера: в `remote`-режиме все действия проверяет сервер (клиент не может читерить), в `local`-режиме игра целиком работает в браузере — удобно для разработки и демо.

### Переиспользуемые компоненты

- `ui/` — `Panel`, `Crt` (зелёный ЭЛТ-экран), `Button`, `Bar`, `Tabs`, `Modal`, `Readout`, `Stepper`, `ChoiceCard`, `ItemRow`, `Toasts`.
- `art/` — `Creature` (гуманоид/зверь, режим каркаса для прицела, раны, смерть), `Gore` / `HitSplat` / `Wound`, `Scene` (17 фонов локаций), `ItemIcon`, `NavIcon`, `WorldMap`.

## Запуск

Нужен Node 22+.

```bash
npm install
npm run dev          # фронт на http://localhost:5173, local-режим (сохранение в localStorage)
npm test             # тесты движка и сервера
npm run typecheck
```

С сервером:

```bash
DEV_AUTH=1 npm run dev:server                                   # API на :8787
VITE_API_MODE=remote VITE_DEV_USER=alice npm run dev            # фронт ходит в API через прокси Vite
```

## Продакшен и Telegram

1. Создай бота у [@BotFather](https://t.me/BotFather), получи `BOT_TOKEN`.
2. Собери фронт и запусти сервер — он сам раздаёт `apps/web/dist` и API:
   ```bash
   npm run build
   BOT_TOKEN=... PORT=8787 npm start
   ```
   Состояния игроков пишутся в `apps/server/data/players.json` (путь меняется через `DATA_FILE`).
3. Выставь сервер наружу по HTTPS (Telegram требует https) и укажи этот адрес боту:
   ```bash
   BOT_TOKEN=... WEBAPP_URL=https://твой-домен npm run bot -w @radclub/server
   ```
   Бот поставит кнопку меню «Играть» и на `/start` пришлёт кнопку запуска. Альтернатива — `/newapp` в BotFather.

Сервер проверяет подпись `initData` из Telegram на каждом запросе (HMAC-SHA256, срок жизни 24 часа).
